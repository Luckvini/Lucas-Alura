# Lucas-Alura
Desafio amigo secreto

Esse programa foi criado pensando em selecionar um nome aleatório que você usuário digitar.

Na opção "Digite um nome", voce digitará o nome que desejar, e após isso clicará na opção "Adicionar", feito isso repare que 
criou uma lista com o nome digitado, você poderá digitar quantos nomes desejar.

Após criar a sua lista com os nomes, verá que tem um botao laranja, com as escritas "Sortear amigo", é só clicar nele e o seu nome será 
selecionado totalmente de forma aleatória.
